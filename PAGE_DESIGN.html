1信息架构与页面分类

按用户任务流分为四层：数据层 → 分析层 → 决策层，外加全局导航。共 6 个主页面。

数据层

数据获取与查看

从外部同步开奖数据到本地库，供下游分析。

历史开奖 数据同步
分析层

多维度号码分析

传统统计 + 形态可视化，从不同角度看号码规律。

统计分析 形态分析
决策层

选号与验证

基于分析生成号码，并用历史回测验证策略有效性。

选号预测 回测
全局

跨页面能力

彩种切换、导航、免责声明、主题切换。

顶部导航 页脚

导航方式：顶部水平导航栏（Logo + 彩种切换 + 6 个页面入口），无侧边栏，最大化内容宽度。

路径三：形态分析 + 自定义算法

形态分析（选算法 → 选期号范围 → 运行 → 看图形）

▼

▼

3各页面详细设计

3.1 历史开奖 2D API
/history

页面目标

查看所有期开奖结果，支持按期号/日期检索，球号可视化展示。

布局结构

顶部导航（彩种切换）
筛选栏：期号输入 + 日期范围 + 搜索按钮
KPI 行：总期数 | 最新期号 | 最新日期 | 数据覆盖时间
开奖表格（虚拟滚动，50条/页）
  列：期号 | 日期 | 红球(6个球) | 蓝球(1个球) | 销售额 | 奖池 | 一等奖注数
分页器

组件

  • DataTable + 虚拟滚动（react-window），3000 期不卡
  • Ball 红球 ● / 蓝球 ● 行内展示
  • KpiCard ×4

数据流

GET /api/history?type=ssq&page=1&size=50 → 分页数据；GET /api/history/latest?type=ssq → 顶部 KPI

交互

  • 期号/日期筛选，回车或点搜索触发
  • 行悬停高亮；点击某行展开该期详情（奖级明细）
  • 分页器支持跳页

性能

  • 虚拟滚动：只渲染可视区行，3000 期 DOM 节点 ≤ 50
  • 表格数据分页加载，不一次拉全量
3.2 数据同步 2D API
/sync

页面目标

查看各彩种同步状态，手动触发同步，查看同步日志。

布局结构

顶部导航
彩种状态卡片网格（每彩种一张卡）
  内容：彩种名 | 最新期号 | 最新日期 | 总条数 | 上次同步时间 | 同步状态徽章
操作栏：[同步全部] [仅同步当前彩种]   同步中显示 ProgressBar
同步日志表格：开始时间 | 彩种 | 拉取条数 | 入库条数 | 状态 | 耗时

组件

  • StatusBadge：success(绿) / failed(红) / running(蓝·脉冲)
  • ProgressBar：同步进度（拉取页/总页）
  • DataTable 日志表（最近 20 条）

数据流

GET /api/sync/status → 各彩种状态；POST /api/sync/run?type=ssq → 触发同步；GET /api/sync/logs → 日志

交互

  • 点「同步」按钮 → 显示进度条 → 完成后状态卡自动刷新
  • 同步过程中按钮禁用，防止重复触发
  • 失败日志可展开查看 error_msg

性能

  • 同步是长耗时操作，后端走 BackgroundTasks，前端轮询 status（2s 间隔）
  • 日志表只取最近 20 条
3.3 统计分析 2D API
/stats

页面目标

多维度传统统计：频次、冷热、遗漏、奇偶、大小、区间、和值。

布局结构

顶部导航 + 彩种切换
窗口选择：[近30期] [近100期] [全部]   切换后所有图表联动刷新
Tab 切换：频次 | 冷热 | 遗漏 | 奇偶大小 | 区间和值
频次Tab：红球33柱 + 蓝球16柱（ECharts 柱状图，冷热色阶）
遗漏Tab：号码遗漏值热力图（NumberMatrix + 色阶）
奇偶大小Tab：饼图（奇偶比 / 大小比分布）
区间和值Tab：区间比柱状图 + 和值分布直方图

组件

  • ChartCard + ECharts
  • NumberMatrix 色阶展示
  • 窗口切换 SegmentedControl

数据流

GET /api/stats?type=ssq&range=30 → 全部统计数据一次性返回（后端已缓存）

交互

  • 窗口切换 → 所有图表同步更新
  • 图表支持 hover 查看具体数值
  • 频次图可点击某号码高亮该号历史

性能

  • 后端统计结果按 (type, range) 缓存（LRU），开奖更新时失效
  • ECharts 用 Canvas 渲染，大数据集不卡
3.4 形态分析 3D API
/visualizer

页面目标

用号码作为数学变换参数生成 2D/3D 图形，提取图形特征辅助分析。所有算法后补，首期全部标记"待实现"。

布局结构

顶部导航 + 彩种切换
左侧：算法清单（按类别分组：频域/螺旋/塌陷/伸展收缩/组合）
  每个算法：名称 | 维度(2D/3D) | 状态徽章(已实现/待实现) | 简短说明
右侧主区：
  - 顶部：期号范围选择（最近N期 / 自定义范围）+ [运行] 按钮
  - 中部：VisualizerCanvas（2D Canvas 或 Three.js 3D 场景）
  - 底部：图形特征面板（面积/质心/收敛点等）+ [导出特征JSON] 按钮

组件

  • VisualizerCanvas：统一渲染容器，根据 visualizer 返回的 type 选 2D Canvas 或 Three.js
  • Three.js：本地 three.module.js + importmap，自实现 OrbitControls（拖拽旋转+滚轮缩放+阻尼）
  • StatusBadge：planned(灰·待实现) / implemented(绿)
  • 特征面板：键值对展示，支持一键复制 JSON

数据流

GET /api/visualizers → 算法清单（含 status）；
POST /api/visualizers/{name}/render → 输入期号范围，返回图形数据；
POST /api/visualizers/{name}/features → 返回提取的特征

交互

  • 左侧点算法 → 右侧加载该算法说明；待实现的算法显示"开发中"占位
  • 已实现算法：选期号范围 → 点运行 → Canvas 渲染图形
  • 3D 场景：鼠标拖拽旋转、滚轮缩放、右键平移
  • 特征面板：点「导出 JSON」复制到剪贴板，可粘贴进自定义算法

性能

  • Three.js 仅在进入本页且选择已实现算法时懒加载
  • DPR 钳制 ≤2；非交互时暂停渲染（needsRender 标志）
  • 开发模式显示 FPS / Draw Call / DPR

视觉

  • PBR 材质 + 三点布光（环境光+方向光+半球光）
  • 渐变背景，不堆粒子/自动旋转
  • 红球系暖色、蓝球系冷色，保持语义一致
3.5 选号预测 2D API
/predict

页面目标

选择策略（含用户自有算法）生成号码，展示冷热标记，带免责声明。

布局结构

顶部导航 + 彩种切换
参数区：策略下拉 | 生成注数(1-10) | [生成] 按钮
免责横幅：⚠️ 本结果为统计选号，中奖概率与纯随机等价
结果区：每注一行 = 6红球 + 1蓝球，球号下方标冷热(热🔥/冷❄️/温·)
策略说明卡：当前策略的逻辑简述

组件

  • Ball + 冷热标记
  • 策略下拉（含用户自有算法，自动从 custom_algorithm 加载）
  • 免责横幅（固定在结果上方，不可关闭）

数据流

GET /api/strategies → 策略列表；POST /api/predict → 生成号码

交互

  • 选策略 + 注数 → 点生成 → 结果区渲染
  • 每注可点「复制」复制号码文本
3.6 回测 2D API
/backtest

页面目标

用历史数据滑动窗口回测策略命中率，与随机基线对比，展示 p-value 证明"策略≈随机"。

布局结构

顶部导航 + 彩种切换
参数区：策略下拉 | 训练窗口 | 回测期数 | [运行回测]
KPI 行：回测总期数 | 平均中红球 | 中蓝球概率 | 一等奖次数
命中分布柱状图：0-6红球命中频次（策略 vs 随机基线对比）
诚实性结论卡：p-value = X.XX → 策略与随机无显著差异（若 p>0.05）

组件

  • KpiCard ×4
  • ChartCard 对比柱状图（策略柱 + 随机基线虚线）
  • 结论卡：p-value 高亮显示

数据流

POST /api/backtest → 回测结果（含 p-value）

交互

  • 点运行回测 → 显示进度条 → 完成后渲染图表和结论
  • 柱状图 hover 查看具体命中次数

诚实性硬约束

  • 结论卡必须显示 p-value，不允许隐藏
  • 若 p > 0.05，文字明确写"该策略与纯随机无统计学显著差异"
