可视化算法说明手册

用大白话讲清楚每个算法"是什么、号码怎么变图形、能看出什么" · 配具体号码示例

阅读提示：每个算法都按 「是什么 → 号码怎么用 → 举个例子 → 能看出什么」 四段写，尽量不用公式，必要时用生活类比。双色球号码格式：红球 01-33（6个）+ 蓝球 01-16（1个）。

频域

A. 傅里叶闭合曲线

是什么

任何一条闭合的曲线，都可以看成是很多个不同频率的"波浪"叠加出来的。就像声音是不同频率声波的叠加，图形也是不同频率"图形波"的叠加。

类比：你在水面上同时扔好几颗石子，每颗石子产生一圈涟漪。涟漪互相叠加，最终水面的形状就是"傅里叶曲线"。每颗石子的大小决定那圈涟漪的强度。

号码怎么用

  • 6 个红球 → 6 个"石子"的大小（振幅），号越大那圈涟漪越强
  • 蓝球 → 整体的旋转角度（相位）

举个例子

假设某期红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 第 1 颗石子大小=3，第 2 颗=11，…第 6 颗=33；整体旋转 9°
→ 把这 6 圈涟漪叠加，得到一条独一无二的闭合曲线，就是这期号码的"图形签名"

能看出什么

  • 不同期号 → 不同曲线形状，可对比"形态演变"
  • 曲线包围的面积、对称程度、自交点数量 → 传统统计没有的新维度
频域

B. Lissajous 图形

是什么

示波器上常见的花纹。一个点在水平方向按某个频率左右摆动，垂直方向按另一个频率上下摆动，两个运动合起来画出的轨迹就是 Lissajous 曲线。

类比：想象一个钟摆同时在左右摆和前后摆，两个方向摆动快慢不同，摆锤画出的轨迹就是 Lissajous 图形。两个频率比不同，花纹完全不同。

号码怎么用

  • 红球两两配对 → 水平频率、垂直频率（如第1、2个红球）
  • 蓝球 → 两个摆动的时间差（相位）

举个例子

红球 [03, 02, 17, 22, 28, 33]，取前两对：水平频率=3，垂直频率=2
→ 频率比 3:2 → 画出一个上面3个鼓包、侧面2个鼓包的编织花纹
蓝球 09 → 时间差 9 个单位 → 花纹整体旋转一点

能看出什么

  • 频率比决定花纹复杂度，整数比时曲线闭合
  • 蓝球变化 → 花纹旋转，可观察"形态偏转"规律
轨迹

C. 3D 时空轨迹

是什么

把每期号码当成 3D 空间里的几个点，多期连起来看就像一条在空间里"游走"的轨迹。

类比：就像飞行记录仪记录飞机的飞行轨迹，我们记录每期号码在 3D 空间的位置。连续看很多期，就能看到"号码"在空间里怎么走动。

号码怎么用

  • 6 个红球 → 拆成 3 组，每组 2 个数作为 3D 坐标 (x,y,z)，得到 3 个点
  • 或者把 6 个数直接当 2 个 3D 点的坐标
  • 蓝球 → 点的颜色或大小

举个例子

红球 [03, 11, 17, 22, 28, 33]
→ 点1 = (3, 11, 17)，点2 = (22, 28, 33)
→ 下一期红球 [05, 08, 19, 21, 26, 30]
→ 点1 = (5, 8, 19)，点2 = (21, 26, 30)
→ 把点1 们连起来、点2 们连起来，得到两条 3D 轨迹线

能看出什么

  • 轨迹是否在某个空间区域聚集（"号码常去的地方"）
  • 轨迹的游走方向、步长变化
频域

D. 球面调和变形球

是什么

在一个完美的球面上，用号码控制不同位置的"凸起程度"，生成一个凹凸不平的变形球。

类比：像捏橡皮泥球，号码告诉你哪里捏高一点、哪里按低一点。每个号码对应球面上一个"捏"的力度和方向。

号码怎么用

  • 红球 → 球面上不同"模式"的凸起强度（球谐系数）
  • 蓝球 → 整体缩放

举个例子

红球 [03, 11, 17, 22, 28, 33]
→ 模式1凸起=3，模式2=11，…模式6=33
→ 球面上出现 6 种不同的凹凸组合，形成一个独特的"土豆形"

能看出什么

  • 变形球的体积、表面积、对称破缺方向
  • 哪一极鼓得更厉害 → 号码的"偏向"
动力系统

E. 混沌吸引子

是什么

有些数学规则迭代很多次后，轨迹会被"吸"到一个特定的形状上，这个形状叫吸引子。最有名的是洛伦兹吸引子，长得像蝴蝶翅膀。

类比：像水流进漩涡，不管从哪里开始流，最终都会被卷进漩涡的固定形状里。号码就是"水流的起点"。

号码怎么用

  • 红球 → 动力系统的初始位置（起点坐标）
  • 蓝球 → 系统的某个参数（如漩涡强度）

举个例子

红球 [03, 11, 17] → 起点 (3, 11, 17)，放入洛伦兹系统迭代 10000 步
→ 轨迹被吸进蝴蝶形吸引子
→ 不同号码起点 → 进入吸引子的路径不同，但最终都绕着蝴蝶翅膀转

能看出什么

  • 号码落入哪个"盆地"（最终绕哪个翅膀转）
  • 进入吸引子的耗时、绕圈数
图论

F. 共现网络图

是什么

把 33 个红球号当成 33 个"人"，如果两个号码在同一期同时出现过，就在他们之间连一条线。出现越多，线越粗。

类比：社交关系图。经常一起出现的号码就是"好朋友"，连线粗；从不一起出现的就是"陌生人"。

号码怎么用

  • 每期 6 个红球 → 在这 6 个节点之间两两连线
  • 多期累计 → 连线粗细 = 共同出现次数

举个例子

统计 100 期后，发现号码 03 和 17 同时出现了 12 次，03 和 33 只同时出现 1 次
→ 03 和 17 之间连粗线，03 和 33 之间连细线
→ 形成一张"号码社交网"，可以看出哪些号是"核心枢纽"

能看出什么

  • 哪些号码是"枢纽"（连接最多）
  • 哪些号码团频繁一起出现
螺旋

G. 螺旋骨架傅里叶

是什么

和 A 类似，但不是画闭合曲线，而是把傅里叶波浪叠加在一条螺旋线上。就像在螺旋楼梯上贴波浪贴纸。

类比：A 是在圆圈上画波浪（闭合），G 是在螺旋线上画波浪（开口，越转越往里或越往外）。

号码怎么用

  • 红球 → 螺旋上 6 阶波浪的振幅
  • 蓝球 → 螺旋的紧密度（蓝球大，螺旋收得紧；小，螺旋张得开）

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 螺旋紧密度=9，6 阶波浪振幅分别是 3,11,17,22,28,33
→ 得到一条一边旋转一边起伏的开口螺旋曲线

能看出什么

  • 螺旋的圈数、收尾方向、振幅包络的"呼吸"节奏
  • 蓝球大 → 螺旋紧，蓝球小 → 螺旋松
螺旋

H. 极坐标傅里叶玫瑰

是什么

在极坐标里（用"距离 + 角度"表示位置），距离随角度按傅里叶方式变化，画出来像一朵多瓣的花。

类比：像花瓣的轮廓，每个号码决定一瓣花瓣的大小。号码组合不同，花瓣数量和大小不同。

号码怎么用

  • 红球 → 极径 r(θ) 的傅里叶系数，决定花瓣大小
  • 蓝球 → 整体旋转角度

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 6 个系数 → 生成一朵有若干花瓣的"玫瑰花"
→ 蓝球 9 → 花整体旋转 9°

能看出什么

  • 花瓣数、花瓣大小分布、对称性破缺方向
螺旋

I. 斐波那契螺旋点阵

是什么

按黄金角（137.5°）排列点，形成向日葵籽盘那样的螺旋点阵。号码决定每个点离中心多远。

类比：向日葵籽盘。每颗籽按 137.5° 排，号码大的籽排外圈，号码小的排内圈。

号码怎么用

  • 7 个号（6红+1蓝）→ 7 个点，按黄金角排列
  • 每个号的值 → 该点离中心的距离（号越大越靠外）

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 7 个点：距离分别为 3,11,17,22,28,33,9，角度按 0°,137.5°,275°,412.5°...排列
→ 形成一个 7 点的小型向日葵图案
→ 号码聚集 → 点团塌陷在一起；号码分散 → 盘面展开

能看出什么

  • 点团的聚集程度（号码是否集中）
  • 点阵的疏密分布
塌陷

J. 引力坍缩轨迹

是什么

把 6 个红球当成 6 个有质量的小球，让它们在引力作用下互相吸引，最终向中心塌缩。记录每个球的运动轨迹。

类比：6 颗星星互相吸引，最终撞到一起。号越大的星星质量越大，引力越强。

号码怎么用

  • 红球 → 6 个质点的质量（号越大质量越大）
  • 蓝球 → 引力常数 G 或时间步长（决定坍缩快慢）

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 6 个球质量=3,11,17,22,28,33，随机撒在圆盘里
→ 引力常数=9，模拟它们互相吸引
→ 质量大的球（33,28）吸引其他球更快，最终所有球塌缩到一个点
→ 记录每个球的运动轨迹

能看出什么

  • 坍缩时间（号码越大整体坍缩越快）
  • 是否对称坍缩（号码分布均匀→对称，不均匀→歪斜）
  • 最终收敛点坐标（可作自定义算法输入）
塌陷

K. 吸引子盆地塌缩

是什么

和 E 类似，但关注的是轨迹被吸入吸引子的过程。不同起点的轨迹像水从不同地方流进下水道，路径不同但都汇到同一个"洞"。

类比：洗手池放水，不管水从哪个位置开始流，最终都流进下水口。号码就是水的起点，看它怎么螺旋流进"洞"里。

号码怎么用

  • 红球 → 动力系统的初始位置
  • 蓝球 → 系统参数

举个例子

红球 [03, 11, 17] → 起点 (3,11,17)
→ 迭代杜芬方程，轨迹螺旋吸入吸引子
→ 记录：螺旋圈数=127，收敛耗时=4.3s，最终落入左盆地

能看出什么

  • 落入哪个"盆地"（可作自定义算法输入的盆地编号）
  • 收敛耗时、螺旋圈数
塌陷

L. 多边形塌缩

是什么

6 个红球决定一个六边形的 6 个顶点离中心多远，然后让这个六边形向中心收缩消失。

类比：像一把伞慢慢收拢。6 个伞骨的长度由 6 个红球决定，蓝球决定收拢速度。

号码怎么用

  • 红球 → 六边形 6 个顶点的半径（极坐标）
  • 蓝球 → 收缩的衰减系数（蓝球大，收缩快）

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 六边形顶点半径=3,11,17,22,28,33（很不均匀）
→ 衰减系数=9，收缩较快
→ 收缩过程中形状会"歪斜"（因为半径差异大），最终缩成一个点

能看出什么

  • 号码差异大 → 收缩过程歪斜；号码接近 → 对称正六边形收缩
  • 收缩轨迹的"歪斜程度"反映号码离散度
伸展收缩

M. 呼吸球面

是什么

一个球面像心跳一样周期性地膨胀、收缩。号码决定球面不同位置的起伏程度。

类比：像一个会呼吸的气球。号码决定气球表面不同地方鼓多高、缩多深，蓝球决定呼吸快慢。

号码怎么用

  • 红球 → 球面各阶球谐系数，决定哪里鼓哪里凹
  • 蓝球 → 呼吸的基频（蓝球大，跳得快）

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 球面有 6 种凹凸模式，呼吸频率=9
→ 球会一边凹凸变形，一边整体扩大缩小，像心跳

能看出什么

  • 呼吸振幅、对称破缺方向（哪一极鼓得更厉害）
  • 蓝球 → 心跳节奏
伸展收缩

N. 形态渐变（Homotopy）

是什么

从上一期号码生成的图形，平滑地"变形"到本期号码生成的图形，中间的变形过程就是动画。

类比：像变形金刚从汽车变成机器人，中间有一系列过渡形态。我们看上期图形→本期图形的"变形过程"。

号码怎么用

  • 上一期号码 → 起始图形
  • 本期号码 → 目标图形
  • 用插值算法生成中间帧

举个例子

上期 [03,11,17,22,28,33] → 起始六边形
本期 [05,08,19,21,26,30] → 目标六边形
→ 播放从起始六边形变到目标六边形的动画
→ 变形过程中自然出现"伸展→塌陷→再伸展"

能看出什么

  • 相邻两期之间的"形变能量"（变化越大，变形越剧烈）
  • 形变过程中的中间形态
伸展收缩

O. 形态学膨胀/腐蚀

是什么

把号码变成黑白图上的白点，然后对白点做"膨胀"（往外长一圈）和"腐蚀"（往里缩一圈），看面积怎么变化。

类比：像在地图上，白点是城市。膨胀=城市扩张一圈，腐蚀=城市缩小一圈。看扩张/缩小后面积怎么变。

号码怎么用

  • 红球 → 在 33×33 网格上点亮 6 个点
  • 蓝球 → 膨胀/腐蚀的"半径"（每次长/缩多大）

举个例子

红球 [03, 11, 17, 22, 28, 33] → 点亮 6 个点
蓝球 09 → 每次膨胀半径=9
→ 膨胀 1 次：点变成 6 个圆，面积变大
→ 膨胀 2 次：圆可能连成片，面积增速变化
→ 记录面积随膨胀次数的变化曲线

能看出什么

  • 面积变化曲线的峰值、周期
  • 点的分布密集度（密集→膨胀后很快连片）
组合

P. 螺旋呼吸叠加

是什么

每期号码生成一条螺旋波，把很多期的螺旋波叠加在一起，像水波干涉。

类比：往水里扔很多颗石子（每期一颗），涟漪互相叠加。共振的地方波纹变大（伸展），抵消的地方变平（塌陷）。

号码怎么用

  • 每期号码 → 一条螺旋波的参数（振幅、频率、相位）
  • 多期叠加 → 干涉图样

举个例子

取最近 10 期号码，每期生成一条螺旋波
→ 10 条波叠加
→ 某些位置共振（波峰+波峰）→ 图样放大
→ 某些位置抵消（波峰+波谷）→ 图样收缩

能看出什么

  • 号码的"周期共振"——哪些期号之间产生强干涉
组合

Q. 螺旋塌缩吸引子

是什么

G（螺旋傅里叶）+ K（吸引子塌缩）的组合。号码生成螺旋曲线，同时这条曲线作为动力系统的轨迹，一边螺旋一边向中心塌缩。

类比：像水流进漩涡时画的螺旋线——一边旋转一边向中心收缩，最终消失在中心。

号码怎么用

  • 红球 → 螺旋的振幅 + 动力系统初值
  • 蓝球 → 螺旋紧密度 + 系统参数

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 生成螺旋曲线，同时曲线各点被吸引子吸引
→ 轨迹一边螺旋一边向中心塌缩，最终收敛到一个点
→ 收敛点坐标 = (x, y)

能看出什么

  • 收敛点坐标（非常适合作自定义算法输入）
  • 螺旋圈数、收缩速率
组合

R. 呼吸螺旋点云

是什么

I（斐波那契螺旋点阵）+ M（呼吸球面）的组合。点阵整体做呼吸缩放，看点与点之间距离的变化。

类比：向日葵籽盘在呼吸——整体扩大再缩小。看籽与籽之间的距离在呼吸中怎么变。

号码怎么用

  • 红球 → 点阵中点的位置（黄金角排列）
  • 蓝球 → 呼吸频率

举个例子

红球 [03, 11, 17, 22, 28, 33]，蓝球 09
→ 7 个点按黄金角排列，呼吸频率=9
→ 点阵整体膨胀收缩
→ 记录每个点最近邻距离随时间的变化

能看出什么

  • 点云"呼吸"的相位差
  • 最近邻距离的周期性
